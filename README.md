O byteshop é um projeto completo de uma loja virtual. Feito em Python utilizando o Django.

É um e-commerce completo, onde o usuário escolherá seus produtos para a compra.

Algumas das características desse projeto:

-O usuário não precisa criar conta para efetuar a compra. Mas se desejar terá essa possibilidade.

-Site está dinâmico, as categorias no menu de navegação só aparecerá se o usuário master cadastrar no /admin

-Cada usuário que criar conta terá uma pagína esclusiva para visualizar e modificar seus dados, visualizar seus pedidos finalizados, seus endereços, mudar senha e fazer logout.

-O usuário anônimo terá o seu carrinho salvo nos cookies do navegador para que caso feche a janela ele não perca seus itens salvos no carrinho.
